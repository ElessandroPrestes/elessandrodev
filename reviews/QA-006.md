## 1. Verificação de Scripts e Arquitetura de CI

1. **Script de Teste em `package.json`:**
   - `"test": "node src/services/aiService.test.mjs"`.
2. **Resiliência do Runner de Testes (`aiService.test.mjs`):**
   - Configurado para aceitar `process.env.VITE_GEMINI_API_KEY` vindo do runner do GitHub Actions (Secrets), sem depender da existência de `.env` físico.
3. **Pipeline do GitHub Actions (`.github/workflows/deploy.yml`):**
   - Inserida etapa intermediária bloqueante `Run automated tests` antes do `Build project`:
     ```yaml
     - name: Run automated tests
       env:
         VITE_GEMINI_API_KEY: ${{ secrets.VITE_GEMINI_API_KEY }}
       run: npm test
     ```
